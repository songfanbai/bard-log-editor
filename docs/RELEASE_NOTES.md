# 1.1.5-rc.9 测试版
- 角色列表新增“字体”，复用全局字体选择器，支持搜索、候选、手动输入及按授权读取本机字体。默认跟随全局字体，可随时恢复。
- 角色头部与主体正文使用角色字体；正文引用使用被提及角色字体，未指定则跟随全局。时间、服务器、类型标记继续使用全局字体。
- 隐藏角色字体锁定；合并沿用目标字体；删除身份后对应普通文字恢复全局字体。
- 字体保存到项目及角色与排版配置，旧文件缺少字体时跟随全局。预览与 Word 共用分片字体规则，Word 每个文本片段写入 ascii/hAnsi/eastAsia/cs。
- 不改变解析、字号、配色、加粗、斜体，不打包或嵌入字体文件。

Windows Chrome / file:// 回归验证通过，包括六类型混排、引用、全局切换、合并删除、隐藏、项目/配置恢复、旧项目默认及真实 DOCX 字体 XML。测试字体：楷体、Arial、宋体及 Georgia。干净 ZIP 离线验证通过，详情见 docs/VALIDATION-rc.9.md。
接收者没有安装字体时 Word 可能替换，排版可能变化；未在桌面 Word 实际验证字体呈现及分页，未验证其他浏览器/操作系统和真实中文输入法。
仍为预发布：不可信项目安全校验、大于30 MiB项目无法重开等既有问题未在本轮处理。重要内容请备份项目和界面配置。
ZIP 内 HTML 使用完整中文名；GitHub 独立附件使用 bard-log-editor.html，中文显示标签保持不变。无许可证变更，未启用 Pages。
