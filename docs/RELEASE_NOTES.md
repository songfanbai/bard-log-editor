# 1.1.5-rc.4 测试版发布说明

- 补充仅时间＋类型标签输入：`[3:13] [Emote]木石点头。`，同样适用于 Say、Party、Shout、Yell。日期留空，复用原有职业及角色边界判断；非法时间进入待确认。

- 离线整理说话、小队、动作、呼喊、喊话和掷骰记录，支持可选时间和人工修正。
- 角色改名、正文引用、配色、隐藏、筛选、跳转和手动合并；正文编辑、删除和撤销重做。
- IndexedDB本机浏览器保存、旧恢复副本迁移、草稿保留及独立项目文件备份。
- 更新角色工具栏固定布局、统一操作样式和可折叠使用帮助。
- 可编辑Word导出，保留字体、配色及排版；无运行时在线依赖。

附件：`吟游诗人随手记·对话log编辑器.html` 可独立离线打开；`bard-log-editor-1.1.5-rc.4.zip` 含同名入口、说明和虚构示例。

本次更新：五种类型标签均支持仅时间输入，修复 `[3:13] [Emote]…` 未进入标签解析的问题；通过 120 组新增解析测试及原有回归测试。README 明确仅适配 FF14，提供验证过的格式示例及单文件下载。页面标题及用户配置保持不变。
