# 1.1.5-rc.4 测试版发布说明

- 离线整理说话、小队、动作、呼喊、喊话和掷骰记录，支持可选时间和人工修正。
- 角色改名、正文引用、配色、隐藏、筛选、跳转和手动合并；正文编辑、删除和撤销重做。
- IndexedDB本机浏览器保存、旧恢复副本迁移、草稿保留及独立项目文件备份。
- 更新角色工具栏固定布局、统一操作样式和可折叠使用帮助。
- 可编辑Word导出，保留字体、配色及排版；无运行时在线依赖。

附件：`吟游诗人随手记·对话log编辑器.html` 可独立离线打开；`bard-log-editor-1.1.5-rc.4.zip` 含同名入口、说明和虚构示例。

本次更新：精简 README，明确仅适配 FF14；增加经过解析器验证的格式示例和单文件直接下载。仅调整交付名称及说明，未修改运行时解析、页面标题或用户配置。原测试版标签保留，更新后的构建脚本与说明见 main 分支。

改名可能影响原 file:// 存储读取。升级前在旧入口下载项目及界面配置，在新版导入核对。源码仓库不堆积ZIP。

重要限制：不可信项目文件导入安全问题及大于30 MiB项目无法重新打开的问题仍未修复；仅发布为预发布测试版。不要打开不可信项目，请控制项目规模并保留独立备份。其他浏览器、真实中文输入法及桌面Word字体分页未完整验收。

未选择开源许可证。未启用GitHub Pages或其他网站部署。

GitHub 会转换中文附件文件名。独立 HTML 的显示名称为完整中文名，实际下载名为 bard-log-editor.html；ZIP 内为完整中文名。
