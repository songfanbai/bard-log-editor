# 1.1.5-rc.7 测试版
- 类型与角色窗口：内容独立滚动，确认修改/取消固定在底部；限制正文和原文区域高度，适配窄窗口。
- 用打开时的有效数据快照判定变化。首次打开、聚焦、无变化确认/外部退出、编辑后恢复原值不创建修正、撤销步骤或未保存状态。
- 历史修正保持不变，入口明确标为“清除该行历史修正”；确认与外部提交共用判断，取消及 Esc 不提交。
- 修复原因：旧逻辑仅对已确认记录跳过无变化提交，首次打开仍会创建修正。本次移除该条件，并在校验前比较快照；打开时的正文引用模型也使用副本，避免读取窗口改变项目。
- Windows Chrome 自动化：新旧弹层、三种窗口尺寸、撤销重做、拖放、项目恢复及原回归通过；干净 ZIP 离线验证通过。详见 docs/VALIDATION-rc.7.md。
- 未实测真实中文输入法、其他浏览器/系统及桌面 Word 渲染。仍有不可信项目安全校验、大于 30 MiB 项目无法重开等既有问题，继续预发布，不作为正式稳定版。
升级前下载项目及界面配置。ZIP 内入口保持“吟游诗人随手记·对话log编辑器.html”；GitHub 单文件附件仍使用 bard-log-editor.html（平台中文名称转换限制）。不新增许可证、不启用 Pages。
