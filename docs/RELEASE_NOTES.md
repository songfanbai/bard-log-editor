# 1.1.5-rc.5 测试版

- 新增 TXT 拖放：拖入窗口后选择“导入并替换”“追加到当前日志”或“取消”，不默认覆盖。
- 拖放与按钮导入复用 UTF-8 读取及解析流程，支持 BOM、大小写扩展名和不同换行；一次处理一个文件，沿用 30 MiB 限制。
- 保留正文草稿与未保存项目保护。解析在独立快照上完成，失败不产生半导入状态。
- 更新使用帮助、README 和拖放回归测试；保留仅时间＋类型标签输入及已有全部功能。

## 下载与升级

独立 HTML 可离线打开；ZIP 内入口为“吟游诗人随手记·对话log编辑器.html”，另含中文说明、虚构示例及已知限制。GitHub 将中文附件名转换，直链附件仍用 bard-log-editor.html，中文显示标签保持不变。
升级前在旧版下载项目和界面配置，再打开新版导入核对。移动或改名 HTML 可能影响本机浏览器副本读取；不要先清除旧数据。

## 验证及限制

Windows / Chrome 自动化验证：文件拖放事件、子元素进出、普通文本拖动、替换/追加/取消、草稿与未保存保护、UTF-8/BOM/无效编码、多文件/空文件/超限/读取失败、解析失败回滚、撤销重做，以及实际下载项目与 Word。单文件及干净 ZIP 解压入口在 HTTP(S) 阻断环境通过相同测试。完整回归及 Word XML 检查通过，详见 docs/VALIDATION-rc.5.md。

测试使用 DataTransfer 模拟系统文件拖放，未实测从资源管理器鼠标拖入、真实中文输入法、其他浏览器/操作系统及桌面 Word 渲染。
不可信项目文件的安全校验尚不完整；超过 30 MiB 的项目无法重新导入。仍为预发布测试版，请只打开可信项目并保留独立备份。
未新增许可证，未启用 GitHub Pages。
