# 1.1.5-rc.12 验证结果

2026-11-03，Windows / Chrome 156.0.8078.80 / Node 24.22.1 / Playwright无头，file:// 且 offline:true。

## 根因
原上一批/下一批按钮与字体项在同一滚动区，导航会被滚走；全局列表静态嵌在侧栏，角色列表绝对定位在可滚动dialog内，受父容器裁切。旧focusout关闭逻辑不适合新列表内的搜索、翻页。单纯提高z-index不能跨过modal的顶层。

## 修复
共用组件拆分固定搜索与分页、中间独立滚动；使用manual popover顶层与视口固定坐标，依据上下可用空间及角色确认按钮位置决定方向和高度，限制窗口边界。监听滚动、resize和visualViewport变化；监听只在打开时注册、关闭时清理，节点移除时也关闭。外部点击与焦点移出关闭，内部交互不误关。无新增遮罩；原角色弹窗遮罩沿用原有机制。
弹层搜索不改当前配置，选中才应用。原设置输入框仍允许直接手动输入并实时预览。角色输入框Esc仍取消角色编辑；候选区Esc先关闭候选。保存/Word规则不变。
