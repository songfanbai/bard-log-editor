# 当前已知限制

版本：1.1.5-rc.4 测试版。以下问题尚未修复，不标记为稳定版。

1. 导入不可信项目存在安全风险：手动修正记录的结构字段校验不完整，可能被拼入预览HTML属性，且当前CSP允许内联脚本。已通过仅修改测试变量的隔离测试复现；不要打开不可信项目，不建议直接公开部署网站。需修正导入校验、渲染及CSP后再验收。
2. 所有导入统一限制30 MiB，而浏览器保存及项目下载可能超过该大小。约54.8MB有效项目曾被“打开项目”拒绝。不要依赖超限项目下载作为可重新导入的备份，暂应控制日志规模；不要手工拆分项目JSON。
3. IndexedDB属于本机当前浏览器的辅助恢复，不保证永久保存；同一来源多窗口并行编辑尚无协调机制。
4. file:// 在不同浏览器中的存储策略可能不同；移动入口、隐私模式、清理数据等可能导致副本不可见。
5. 字体不嵌入Word；接收者字体及Word排版可能不同。真实中文输入法、桌面Word实际字体分页、其他系统/浏览器和真机移动体验未完整验收。
6. 撤销重做最多40步，不跨会话恢复。图片图标转为小型静态PNG；动态图片不会保留动画。
7. 此仓库没有云同步、服务器后端、GitHub Pages或PWA服务；离线使用请保留分享包及独立项目文件。

升级：先提交正文草稿、下载项目并核对，再导出界面配置；打开新版导入核对。不清除旧浏览器数据。
