# 1.1.5-rc.10 验证结果

## 根因及修复
原 parse/ensure 始终保留历史角色数组，列表只排除合并来源和已删除身份，因此移除原文不会移除列表条目。不是刷新或缓存单独失效。
解析完成后按未删除记录的主体和有效正文引用计算角色使用状态。无使用的自动角色标记 inactive，退出列表及选择/配色范围；身份及设置保留在项目中供重新出现时复用。手动角色、隐藏角色保留；重定向身份、删除排除和手动引用不删除。打开项目时也重新核对实际使用状态。列表计数取完整有效记录，保持拼音排序及搜索。失效筛选、跳转游标清理。
重新解析沿用隔离副本解析、确认冲突后整体提交；撤销恢复整个项目快照。
