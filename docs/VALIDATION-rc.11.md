# 1.1.5-rc.11 字体列表验证

日期：2026-11-03。环境：Windows、Node 24.22.1、Chrome 156.0.8078.80、Playwright无头、file://、offline:true。

## 原因和修复
原 queryLocalFonts 读取结果按family去重，并未限制数量；搜索在全量数组上进行。显示层 names.slice(0,150) 导致只能浏览前150项。
改为每批60项、前后批导航，无总数截断。搜索仍全量，结果数量与范围实时显示。展开时选择当前字体所在批次并只滚动候选区到选中项；全局与角色共用逻辑。不改变字体配置、项目格式或Word字体写入。

## 实际测试
- 浏览器注入 queryLocalFonts 返回4000个变体，去重2000家族，加21备用候选。逐批遍历34批，核对2021个唯一项，无遗漏；每批最多60个字体按钮。
- 搜索Test Font 1999，只有一个匹配；清空恢复全量2021。重新展开选中项正确定位到最后一批。
- 全局字体Test Font 1999、角色字体Test Font 1900保存并重新打开项目，两个选择器均定位正确；角色搜索/选择1998正常。实际document.xml生成字符串包含角色字体eastAsia设置。
- 模拟拒绝授权后提示正确，手动输入仍可更新全局设置。
- 首次读取及首批显示164ms，遍历34批约1057ms，搜索末尾12ms（单次无头测试，含自动化开销，不是保证值）。没有发现明显卡顿。
- 完整 scripts/test.cjs --browser：日志解析、角色同步与字体、正文引用、配色、修正、拖放TXT、项目和DOCX下载、IndexedDB保护及恢复、帮助和400角色布局回归。

## 未验证及边界
2000字体是测试注入，不是实际安装或经系统授权枚举的字体；本轮未重新验证真实字体权限对话框。浏览器实际只返回授权环境下可见字体，本应用不能保证系统所有隐藏/受限字体均可枚举。字体文件不上传、不打包、不嵌入Word。真实Word字体呈现/分页、真实中文输入法、其他浏览器/系统未验证。原有测试版限制不变。
