# 吟游诗人随手记·RP log编辑器

仅适配《最终幻想 XIV》（FF14）的 RP 日志，不是通用聊天记录编辑器。支持角色识别、改名、配色、正文编辑及可编辑 Word 导出，日志在本地浏览器中处理。

## 快速下载与使用

**[下载单文件 HTML](https://github.com/songfanbai/bard-log-editor/releases/download/1.1.5-rc.6/bard-log-editor.html)** · [下载完整 ZIP（含说明和示例）](https://github.com/songfanbai/bard-log-editor/releases/download/1.1.5-rc.6/bard-log-editor-1.1.5-rc.6.zip)

下载 HTML 后，在电脑浏览器中打开即可离线使用，无需安装。GitHub 会转换中文附件文件名，因此直接下载名为 `bard-log-editor.html`；可在首次使用前改名为 `吟游诗人随手记·对话log编辑器.html`。ZIP 内已使用完整中文名，解压后打开即可。

**导入 TXT → 检查“待确认” → 调整角色与排版 → 保存项目／导出 Word。**

也可将 TXT 拖入窗口，选择“导入并替换”或“追加到当前日志”，取消不会改变项目。一次一个文件，支持 UTF-8（可带 BOM）。

继续添加日志用“追加 TXT”；字体在常用设置，字号在高级设置。详细操作见右上角“使用帮助”。

## 支持格式及示例

格式 1：

```csharp
[15:21]云舟静语庄园 : 大家小心。
[15:22]云舟静语庄园赶紧带上兜帽。
[15:23](骑 云舟静语庄园)这里可以钓鱼。
```

格式 2：
```less
[3:13] [Say]云舟静语庄园: 好。
[3:13] [Emote]云舟静语庄园点头。
[3:13] [Party]云舟静语庄园: 走吧。
[3:13] [Shout]云舟静语庄园: 看这里！
[3:13] [Yell]云舟静语庄园: 好！
```

格式 3：

```csharp
[2026-09-16 19:59] [Say]云舟静语庄园: 大家小心。
[2026-09-16 20:01] [Party]云舟静语庄园: 这里可以钓鱼。
[2026-09-16 20:02] [Emote]云舟静语庄园赶紧带上兜帽。
[2026-09-16 20:03] [Shout]云舟静语庄园: 大家看这里！
[2026-09-16 20:04] [Yell]云舟静语庄园: 马上过来！
```

掷骰：

```less
[20:38]云舟静语庄园掷出了69点！（最大100）
[2026-01-31 20:38]云舟静语庄园掷出了69点！（最大100）
```

- 时间和服务器可以省略，角色名必须存在。格式2标签不区分大小写，依次对应说话、小队、动作、呼喊、喊话。
- 两种格式的小队职业结构不同：格式1为括号内“前导字符＋职业单字”；格式2为可选单字符职业标记，不能混用。特殊字符属于日志内容，不是需手动添加的装饰。
- 解析会结合全文及手动角色列表。以上每组可直接导入；孤立的格式2小队记录若无法确定职业与角色名分界，需在“待确认”修正，不会猜测截断姓名。
- 带标签格式也支持仅有时间，例如 `[3:13] [Emote]云舟静语庄园点头。`；日期保存为空，不自动补齐。动作仍需已知角色身份来判断姓名与正文分界。

## 保存与注意事项

- “保存到本机浏览器”不是云端同步；重新打开可从“本机副本”恢复。清理浏览器数据、移动或改名 HTML、更换浏览器或电脑可能影响读取，重要内容请下载项目文件备份。
- “保存项目”保留可继续编辑的完整状态；普通下载后请核对文件，再点击“确认已保存”。Word 用于阅读分享，不能代替项目文件。
- **升级或改用本次新文件名前，先下载项目及界面配置备份**，在新版导入并核对，不要先清除旧数据。
- 字体不会嵌入 Word；接收者未安装字体时，显示及分页可能不同。本机字体读取需浏览器支持并由用户授权，无法读取时可手动选字体。

当前为 **1.1.5-rc.6 测试版**，不是正式稳定版。已知问题：不可信项目文件的安全校验尚不完整；超过 30 MiB 的项目无法重新导入。请只打开可信项目并控制规模。Windows / Chrome 离线运行已测试，其他平台、真实中文输入法及桌面 Word 字体分页尚未完整验收。详见[已知限制](docs/KNOWN_ISSUES.md)。
