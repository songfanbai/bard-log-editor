# 吟游诗人随手记·对话log编辑器

用于整理中文 RP 聊天记录的本地工具，支持角色识别、改名、配色、正文编辑和可编辑 Word 导出。日志在浏览器中处理，无账号、无日志上传、无运行时 CDN。

当前版本：**1.1.5-rc.4 测试版**。存在尚未修复的项目文件安全校验与大项目导入限制，详见 [已知限制](docs/KNOWN_ISSUES.md)。不建议作为正式稳定版或直接部署网站。

## 下载与启动

在仓库的 **Releases** 页面选择该版本，下载附件 `bard-log-editor-1.1.5-rc.4.zip`，完整解压后双击 `双击打开.html`。附件尚未发布时请勿将 GitHub 自动生成的 Source code ZIP 当成离线分享包。

普通使用无需安装 Node.js、Python 或其他开发工具，也无需联网。源码检出后可直接打开 `app/index.html`，需保持同目录 CSS/JS 完整。本仓库不自动启用 GitHub Pages。

## 基本流程

1. **导入 TXT**（UTF-8）；继续添加用 **追加 TXT**，避免替换已有内容。
2. 检查预览和 **待确认**，必要时从角色列表 **手动添加角色**。角色支持改名、配色、隐藏、筛选、跳转及手动合并。
3. 双击正文编辑：Enter 保存、Shift+Enter 换行、Esc 取消。可撤销重做。
4. 常用设置选择字体和显示范围，高级设置调整字号、间距及页面；可填写导出标题。
5. **保存项目**下载完整编辑状态，核对文件下载完成后点击 **确认已保存**。下次用 **打开项目**继续，再 **导出 Word**供阅读分享。

“导出角色与排版／导入角色与排版”只用于跨日志复用角色设置和文档样式，不代替完整项目备份。详细操作见应用右上角“使用帮助”。

## 本机浏览器保存

应用通过 IndexedDB 保存项目与未提交草稿，保留近期两份副本；停止修改约1.8秒后保存，持续编辑时约10秒尝试一次。重新打开后通过 **本机副本**选择恢复，或开始新工作。

请以状态区为准，失败时重试或下载项目。浏览器保存不是云端同步，也不代表独立项目已经下载。清理浏览器数据、隐私模式、移动入口、更换浏览器或电脑，可能无法恢复；重要工作务必下载项目文件。升级前先备份项目及界面配置，不要求清除旧数据。

## 浏览器和字体

主要验证环境为 Windows / Chrome 155 的离线 file:// 模式。其他浏览器及平台未做完整验收，file:// 存储行为不能一概保证。

支持的浏览器可由用户主动授权读取本机字体；不支持或拒绝时使用候选及手动输入。字体文件不会上传或嵌入 Word，接收者缺少字体时可能替换，分页也可能不同。真实中文输入法及桌面 Word 显示仍需补充验收。

## 开发与测试

运行应用不需要安装依赖。开发测试使用 Node.js 20+；打 ZIP 使用 Python 3。

```sh
npm install
npm test
npm run build
npx playwright install chromium
npm run test:browser
npm run package
```

测试浏览器也可通过 `BROWSER_EXECUTABLE` 指定已安装的 Chrome/Chromium 可执行文件。源码和测试没有开发者电脑路径。Playwright 仅为开发测试依赖，不进入离线应用。

- `app/`：应用源码及入口。
- `examples/`：虚构日志。
- `tests/`：可重复执行的回归测试。
- `scripts/`：构建、测试、打包脚本。
- `docs/`：使用说明、验证范围及已知限制。
- `dist/`、`test-results/`：本地生成物，不提交；ZIP 作为 Release 附件发布。
